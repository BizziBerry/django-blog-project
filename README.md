## 📁 Project Structure
```
MyBlog/
├── blog/ # Django application
├── static/ # CSS, images
├── MyBlog/ # настройки проекта 
└── manage.py # Django management script
```

## 🚀 Quick Start
```bash
# Install dependencies
pip install django

# Run migrations
python manage.py migrate

# Create superuser
python manage.py createsuperuser

# Run server
python manage.py runserver
```
